# Протокол FM1828 (проверено на живом устройстве, 2026-09-08)

## Физический уровень

- UART 460800 бод, 8N1, уровни 3.3 V (на TX лидара 3.3 V), питание 5 V, паспортный ток 0.35 A.
- Строка `stty -F %s 460800` в драйвере робота подтверждает скорость.
- В отличие от старого Ecovacs LDS-006 (115200, тот же набор команд), FM1828 — dToF-лидар с 16 точками в кадре.

## Команды (ASCII, терминатор `$`)

| Команда | Действие | Примечание |
| --- | --- | --- |
| `$` | ответ `0x21` (только первый раз после включения), затем непрерывные кадры простоя | режим сохраняется до снятия питания |
| `startldspl$` | ответ `0x21`, мотор раскручивается, поток кадров сканирования | «plus startup», робот шлёт `startldspl$startlds$` |
| `startlds$` | старт; **игнорируется** первой командой после открытия порта — нужен `$` за 2 с до него | |
| `stoplds$` | мотор останавливается за ~1 с, поток возвращается к кадрам простоя | после этого старт не принимается до снятия питания |

Строк других команд в прошивке робота нет (проверено по бинарнику драйвера).
Break на линии RX, длинные нулевые последовательности, регистр, CR/LF, повторы — не влияют.

## Кадр простоя (4 байта)

`5A A5 <dist_hi> <dist_lo>` — дистанция по текущему направлению в мм, big-endian, ~1000 кадров/с.

## Кадр сканирования (62 байта, little-endian)

| Байты | Поле |
| --- | --- |
| 0 | `0xFA` |
| 1 | индекс кадра `0xA0…0xF9` (90 кадров на оборот, 4° каждый) |
| 2–3 | скорость, u16; ~8000–15000 при разгоне, ~29300–30700 в установившемся режиме (единицы неизвестны) |
| 4–35 | 16 дистанций u16, мм; 0 или ≥ 32000 — нет отражения |
| 36–59 | хвост: `00 02 <cnt_lo> <cnt_hi>` и 20 нулей; счётчик 16 бит, ~1600/с |
| 60–61 | контрольная сумма u16 = арифметическая сумма байтов 0…59 |

Угол точки `j` (0…15) кадра с индексом `idx`: `(idx − 0xA0) · 4° + j · 0.25°`.
Установившийся режим: ~446 кадров/с ≈ 4.95 об/с, ~28 КБ/с полезных данных.

## Поведение состояний

```
POWER-ON (тишина) --$--> IDLE-STREAM --startldspl$ / startlds$--> SPINNING --stoplds$--> IDLE-STREAM (заблокирован)
POWER-ON (тишина) --startldspl$--> SPINNING
SPINNING --$--> IDLE-STREAM (заблокирован)
```

Из состояния «заблокирован» выход только снятием питания. Однократно наблюдалось, что примерно через 20 минут
бездействия лидар сам замолкает и после этого снова принимает `startldspl$`; воспроизводимость не подтверждена.
